# One Line One Laugh

Entry for the make.fun competition
`u-deysumbrella-one-line-one-laugh-e0cdcda9`: a program that writes one
original funny line — a single one-line joke — to `/output/entry.txt`.

## The joke

> I bought a smart umbrella; it checks the forecast and tells me to just stay home.

## How to run

```sh
python3 main.py
```

The program writes the joke to `/output/entry.txt` and also prints it
to standard output. It needs no arguments, no network, and no
dependencies beyond Python 3.
